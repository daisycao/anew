# Welcome to Anew

This is an example library, at `~/Documents/Anew Notes/`. It is three days of someone reading with Claude: a small research report, a few classics on time, and the margin notes that shaped them. Edit or delete anything.

## A five-minute tour

1. **Start with the research report.** On the left, open **Model T** → *Model T — a car for everyone*. It was written over three days: read Ford's book, annotate, hand it to Claude, read Taylor, annotate again, retell it out loud. That's version 4.
2. **Open a source.** *Ford 1922* is Ford's own book (public domain). The highlighted sentences are annotations. In the margin you can see what Claude answered and which section of the note each one ended up in. Two are still waiting for Claude (and one more on the report itself).
3. **Click ◎ Graph** (top right) while the report is open. Each column is a version, each line a point: you can watch "the $5 day was a PR stunt" turn into "the $5 day was buying stability". Switch to the category view to see which topics feed your own projects (*Our pricing*, *Reading hour*).
4. **Click ◷ Timeline** to see the last day of reading: which sources were annotated, when, and when Claude answered.

## Then try it yourself

1. In *Ford 1922*, select a sentence → **＋ Annotate** → write what you think, even one line.
2. **Hand to AI ▾** (top right) → **Process annotations**. The prompt is copied; paste it into your AI agent: Claude Code, or Claude Code running DeepSeek, Kimi, Qwen… (with the `anew` skill installed).
3. Within seconds the note rewrites itself: a version 5, your words under 👩, Claude's checks in cards, version 4 kept as `old-…`.

## Use your own folder

**File → Open Library…** (⇧⌘O) and pick any folder of Markdown files. An Obsidian vault works. Anew never changes your files' format; annotations live next to them in a hidden `.paper-md-notes/` folder.
