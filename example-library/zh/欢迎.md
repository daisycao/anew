# 欢迎

这是 Anew 自带的示例库，放在 `~/Documents/Anew Notes/`。里面是一个人和 Claude 一起读了三天的样子：一篇小研究报告、几篇讲时间的老文章，以及把它们改出来的那些批注。随便改、随便删。

## 五分钟看一圈

1. **先看研究报告。** 左边打开「T 型车」→《T 型车：人人买得起的车》。它是三天里写出来的：读福特的自传、划线批注、交给 Claude；再读泰勒、再批注；最后用嘴讲一遍。现在是第 4 版。
2. **打开一篇来源。**「Ford 1922」是福特自己的书（公版）。划过的句子就是批注，右边能看到 Claude 回了什么、每条最后改进了笔记的哪一块。还有两条在等 Claude（报告本身上还有一条）。
3. **点右上角「◎ 图谱」**（开着报告的时候）。一列是一版，一行是一个观点：能看到「5 美元日薪是作秀」怎么变成「5 美元日薪是在买稳定」。切到「分类」看哪些主题流进了你自己的事（「我们的定价」「读书时间」）。
4. **点「◷ 时间轴」**，看最后那天读了什么：哪几篇批注了、几点写的、Claude 几点回的。

## 然后自己试

1. 在「Ford 1922」里选中一句 →「＋ 划线」→ 写下你的想法，一句就够。
2. 右上角「交给 AI ▾」→「处理这篇的回响」。那句话已经复制好了，贴进你的 AI：Claude Code，或者接了 DeepSeek、Kimi、千问……的 Claude Code（装了 `anew` skill）。
3. 几秒后笔记自己改好：多出第 5 版，你的话在 👩 下面，Claude 的查证在卡片里，第 4 版留成「旧版-…」。

## 库里有什么

| 主题 | 看什么 |
| --- | --- |
| **T 型车** | 一篇研究报告：2 篇一手来源、4 版、6 个观点、19 条批注、一次「换位」和一张对照表 |
| **时间就是金钱** | 富兰克林，1748。三版；其中一个观点流进「读书时间」 |
| **一天 24 小时**、**瓦尔登湖** | 本涅特、梭罗。理好了的笔记 |
| **人生不短**、**沉思录** | 塞涅卡、马可·奥勒留。还在学；「人生不短」里有一个「换位」在等你回答 |
| **我们的定价**、**读书时间** | 你自己的事（type: 要接着想）。图谱会画出哪些阅读流到了它们 |

## 换成你自己的文件夹

菜单「文件 → 打开书库…」（⇧⌘O）选任何一个放 Markdown 的文件夹，比如 Obsidian 的库。Anew 不改你的原文格式，批注存在旁边的隐藏文件夹 `.paper-md-notes/`。
