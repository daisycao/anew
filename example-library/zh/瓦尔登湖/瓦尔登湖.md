# 瓦尔登湖

## 1. 从容地生活 #产品

> I went to the woods because I wished to live deliberately. —— Thoreau, 1854

👩 他拿自己的生活做了个实验，然后把结果写了下来。

## 2. 砍掉不必要的 #商业

👩 豆子和木板的账占了半本书。

## 3. 时间是溪流，不是账本 #产品

> Time is but the stream I go a-fishing in. —— Thoreau, 1854

👩 和富兰克林正相反：时间不是拿来花的，是在里面钓鱼的。

> [!claude]
> 这组对照好，不过梭罗自己也记账记得很细。他反对的是把生命浪费在东西上，不是反对算账。

## 4. 读书时间：少读几本，读深 #对我

👩 一本书读两遍，胜过三本翻一翻。
